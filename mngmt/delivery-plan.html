Day 1: what actually happened

Two findings reshaped the plan before a single layer was built.

Resolved ahead of schedule

  • Gated access granted; VCF, index, phenotype doc and README down — 303 MB, one minute, not the feared 85 GB
  • Custody root live on WSL ext4 with HF_HOME set before the first byte; C1 and C2 registered active
  • Miniconda in; DATA.md's open question closed — no expression data, so Channel C is a confirmed proxy, not an assumed one

Two things the plan had wrong

  • Windows cannot run this pipeline at all. pysam and bcftools ship no Windows builds, so WSL2 Ubuntu is the target — not a preference, a requirement
  • There is no BAM. The dataset is raw reads plus a called VCF. L0's Innovation hook had no executable input, and now derives burden from B-allele frequency instead

Assumption, stated because the repo does not record it. No submission deadline appears anywhere in the repository, so this plan runs on a five-week horizon anchored at 2026-10-05. Every phase is week-relative rather than date-locked — if the real deadline differs, shift W1 and the gates travel with it.

Phases and gates

Five gates. Each one is a decision that changes what the next phase is allowed to assume.

W1
Sep 1–7

Unblock the data, build the spine

Nothing in W2 can start without the dataset, and the approval clock is not yours. Start it today, then spend the week on what does not depend on it.

  • Day 0
    Request gated access to SageBio/mva-hackathon-2026-data on Hugging Face, then begin the ~85 GB pull.The only task here with an external approval latency. Everything else in this plan can be reordered; this one cannot be started later and caught up.
  • Data
    Close the DATA.md TODO — enumerate the 11 files and confirm whether any expression data exists.The answer decides whether Channel C runs on a LINCS knockdown proxy or a curated aneuploidy gene set. It is an input to W3, so settle it now.
  • Code
    Implement src/pipeline.py — load_config, seed_everything, and a run that checkpoints after every layer.Per-layer checkpointing is not polish. It is what stops a failed L4 from forcing a re-run of the expensive L2 channels and the paid L3 reasoning step.
  • Code
    Build the fixture contract — small synthetic artifacts matching each layer's output shape, so L1–L5 can be developed while the download runs.Name them .tsv or .json, never .vcf: test_no_patient_data_files_present scans the whole repo for genomic extensions and will fail on a fixture named like real data.
  • Docs
    Replace the L0 and L1 placeholders in docs/architecture.md while the design reasoning is fresh.The written report is a graded deliverable. Assembling it in W5 from memory is how the Scientific Rigor score gets lost.
GATE G0 — PASSED 2026-09-02

Data in hand and inventoried

Access granted, revision pinned at 59e322d2…, inventory written to DATA.md by role rather than by filename — the VCF name embeds a lab accession and a sequencer flowcell ID, so the custody rule against recording filenames turned out to be load-bearing on day one rather than hypothetical.

The gate passed, but not as designed. The dataset is 8 × .fastq.gz (84.67 GB), one single-sample .vcf.gz with index, a phenotype .docx, and a README. No alignments. Only the 303 MB of non-FASTQ was fetched — L0 runs on the VCF, so 85 GB stays out of the custody register and out of the 30-day deletion obligation, still retrievable at the pinned revision if alignment is ever revisited.

The contingency drafted for this gate — a literature-described stand-in genotype — was never needed. What was needed instead was a different innovation hook, which is the sort of thing only inventorying the data can tell you.

W2
Sep 8–14

L0 and L1 — establish the scientific premise

Everything downstream inherits whatever this week concludes. Two config fields come off null here, and only here.

  • L0 · 1-3
    Ingest, annotate, resolve zygosity. Open the VCF with pysam.VariantFile, restrict to the SAC panel plus a configurable extension set, run consequence prediction, then identify biallelic configurations.MVA is autosomal recessive — a single heterozygous LoF is not a causal call. Do not filter to one gene a priori.
  • L0 · 4
    Aneuploidy burden from B-allele frequency. BAF at heterozygous sites from FORMAT/AD; per chromosome, characterize deviation from 0.5 and convert it into a mosaic-fraction estimate.Revised after G0 — there is no BAM to read depth from. This is the stronger feature anyway: an allele ratio at one locus is self-normalizing, so the GC-bias and mappability corrections depth would need never arise, and the magnitude of the split estimates mosaic fraction, which is the quantity the disease is named for. Chromosomes with too few het sites emit insufficient_sites, never a burden of zero.
  • L0 · 5
    Reconcile against the Track-1 validated variant and raise on disagreement rather than silently preferring either source.
  • L1
    Disease module and target split. Causal gene to UniProt to complex (Reactome/CORUM), seed STRING at a recorded confidence cutoff, expand by DIAMOnD or random-walk-with-restart, then partition into upstream and downstream sets by pathway membership.Record the algorithm, every parameter, and the cutoff beside the output. A hand-curated module boundary is unfalsifiable. This layer also carries the Scalability argument, so nothing MVA-specific may be hardcoded.
  • L1
    Attach Open Targets tractability per node so L2 can weight reachable targets. Annotate only — L4 owns every exclusion decision.
GATE G1 — CAUSAL GENE

The premise is a finding, not a setting

Only after L0 reconciles with Track 1 does causal_gene move off null in config/pipeline.yaml — set from the L0 artifact, with that artifact's path and seed recorded next to it.

This gate breaks a test on purpose. test_open_decisions_are_still_open asserts both fields are None. Update it deliberately, so it asserts the value now matches the L0 output, rather than deleting it. The test exists to catch a guess; it should survive the gate as one that catches a changed guess.

GATE G2 — PASSED 2026-09-08

Endpoint is chemoprevention — meaning secondary prevention

The scaffold defined this endpoint as preventing a first cancer. The clinical basis recorded at D4 makes it secondary prevention instead. So the ranked list addresses recurrence and second-primary risk, and the report must say so — the unqualified word overstates the claim.

Settled before G1, without presupposing it. The cancer risk here is established by the phenotype rather than inferred from a genotype, so the endpoint did not have to wait on L0's gene call. mitotic_fidelity is carried as discussion (no approved-drug route, and SAC-directed agents are counterproductive if the checkpoint is already impaired); symptomatic candidates still surface through Channel D tagged as such.

Two consequences already applied: L4's bbb_penetration criterion is not applicable — the documented phenotype does not establish a CNS requirement, so the scaffold's assumption of CNS involvement does not hold — and the genotoxic gate now binds hard, which makes the exclusions table a headline result rather than a loss.

W3
Sep 15–21

L2 — five channels, built in risk order

Solo, one week, five generators. Build cheapest-and-most-robust first, so a week that goes badly still ends with candidates on the table.

  • 1st · B
    Network proximity (Guney/Barabási) between drug-target sets and the disease module.First because it is the only channel needing neither a KG containing MVA, nor an expression signature, nor an LLM. It is the floor under the whole week — ship it Monday and W3 cannot end empty-handed. Degree-normalize: hub proteins are close to everything.
  • 2nd · D
    Phenotype and HPO via Monarch, Orphanet, and Open Targets, reaching the symptomatic candidates the mechanism-first channels structurally miss.
  • 3rd · E
    Aneuploidy-stress literature prior plus agentic mining, emitting PMID-level citations and an evidence grade per claim.Budget time for verification, not just extraction: every PMID resolves against a real record or the row is dropped. Queries carry gene symbols and public HPO terms only — no patient data reaches an external API.
  • 4th · A
    Knowledge-graph link prediction, anchored at the gene node.The expensive one. Timebox training to two days; if it has not converged, degrade to explainable meta-path counting. That keeps the traversable-path requirement, which is the part that is actually admissible, and drops only the learned score.
  • 5th · C
    Signature reversion on a proxy signature, per the W1 expression finding.Last because it is the most over-claimable channel and the most likely to be cut. If LINCS integration stalls, fall back to a curated aneuploidy-response gene set. Either way the proxy caveat travels on every row and every downstream figure.
GATE G3 — END OF W3

Three channels producing, independently

Pass condition: at least three channels have written ranked tables to results/l2/<channel>/ with per-candidate provenance. Below three, cross-channel convergence is not a meaningful signal and L3's aggregation claim weakens — say so in the report rather than aggregating anyway.

Two invariants to hold under time pressure. Channels never read each other's scores; leaked scores manufacture false consensus, which is the exact signal the whole design rests on. And a channel that fails is recorded as failed, never as an empty result — an empty list is a scientific claim, an exception is not.

W4
Sep 22–28

L3 and L4 — integrate, then refuse

The densest week. Order inside it is not negotiable: identity before aggregation, aggregation before reasoning, reasoning before triage.

  • L3 · 1
    Harmonize to RxCUI first. Resolve every candidate onto the RxNorm backbone before any aggregation runs.Aggregating on drug names splits one compound across channels under different synonyms and destroys precisely the convergence signal the ranking depends on. A correctness prerequisite, not a cleanup step.
  • L3 · 2
    Rank-aggregate (RRA or Borda), rewarding cross-channel support, and carry n_channels_supporting on every row.
  • L3 · 3
    Claude reasoning over the top-N — rationale synthesis, active contradiction search, calibrated confidence.Pin the model, record the temperature, cache by RxCUI, checkpoint either side. The reasoning step must never be re-run because a later step failed, and it must introduce no mechanism that no channel cited.
  • L4 · 1
    Safety triage as hard gates. Genotoxic and cancer-risk exclusion, then pediatric use — both drops, never down-weights.Build the genotoxic set from independent signals rather than one flag: ATC L01, MED-RT mechanism classes, IARC/NTP listings, and label Section 13.1 text. Fail closed — undeterminable status is insufficient_evidence and excludes. Absence of a warning is not evidence of safety.
  • L4 · 2
    Annotate from the CC-BY-clean core only — openFDA label, FAERS, drugsfda, RxClass, MED-RT. NC and ShareAlike fields join by RxCUI into the segregated enrichment zone and never reach a redistributed path.Two currency traps to code around: FDA pregnancy letter categories are retired, so parse narrative Section 8; and the RxNav interaction API was discontinued 2024-01-02, so any DDI output needs a licensed source or SPL-NLP, labelled with its provenance.
  • L4 · 3
    Blinded benchmark against known aneuploidy and SAC-relevant compounds with a degree-matched decoy set.Freeze the positive and decoy sets before scoring. There is no external ground truth for Track 2, which makes this benchmark the only honest evidence that the pipeline works — and worthless if it is tuned after the numbers are seen.
GATE G4 — END OF W4

Results are auditable, whatever they say

Pass condition: the surviving-candidate table and the excluded table both ship, each row naming the rule that produced its verdict and the source field it was drawn from. The exclusions table is a headline result, not an appendix — what the pipeline refused to propose for a cancer-predisposed child is as informative as what it nominated.

A benchmark at chance is a finding, and gets reported as one. The response is to say so in the report, not to adjust the positive set until the curve improves. A submission that honestly reports a null result is defensible; one that quietly retuned is not.

W5
Sep 29–Oct 5

L5 and submission

Three deliverables, one compliance sweep, and two days that stay empty on purpose.

  • 15%
    Run the pipeline on a second monogenic disease, changing only the config.This is the entire Scalability criterion, it is cheap if the layers are genuinely disease-agnostic, and it is the only real test of whether they are. Do it Monday — if it fails, you learn that L1 has MVA baked in while there is still time to fix it.
  • Figures
    One figure per claim. Channel convergence, benchmark curves with confidence intervals, aneuploidy burden in aggregate form only, the contradiction-search trace, and the exclusions table.A ranking shown without its uncertainty is a recommendation in disguise. Every candidate table carries the hypothesis-only disclaimer, the Channel C proxy caveat, and the supporting-channel count.
  • Report
    Assemble the written report from the architecture doc you have been growing since W1, with every claim carrying either a results/ artifact path plus seed, or an APA 7th citation with a resolvable DOI.
  • Video
    Cut the 3-minute video. Script it around the safety triage and the convergence figure — the two things that distinguish this from a ranked list.
  • Sweep
    Final governance pass, four checks, in order.Re-resolve every DOI and PMID and re-run the retraction check, since status changes between drafting and submission — that is why docs/references.md keeps a dated verification log. Confirm git ls-files matches no genomic extension. Confirm no NC or ShareAlike field reached a redistributed output. Confirm the attribution block is present.
  • Buffer
    Oct 4–5 hold no scheduled work.Not slack to be filled. On a solo build with an 85 GB dependency and a paid API in the critical path, the buffer is the plan.
